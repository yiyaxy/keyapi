# Design Context — keyapi/web

> 本文件用于约束本项目所有 UI / 视觉 / 交互决策。任何 frontend-design 相关 skill 均应以本文为唯一真源。

## Stack 基线（只读事实）

- React 18 + Vite
- 主组件库：**@douyinfe/semi-ui**（ByteDance Semi Design）
- 次组件库：antd 6（仅个别复杂场景兜底，新页面不要引入）
- 图标：`@douyinfe/semi-icons`、`lucide-react`、`@lobehub/icons`
- 图表：`@visactor/react-vchart` + Semi theme
- Tailwind 3：所有色值、圆角均已绑定到 Semi CSS variables（见 `tailwind.config.js`），**严禁写死十六进制颜色**
- 字体栈：`Lato, 'Helvetica Neue', Arial, 'Microsoft YaHei', sans-serif`
- 默认语言：**zh**；i18n 必须通过 `react-i18next`，不得硬编码中文字符串到组件
- 主题：明暗双主题，跟随 Semi token；body 背景 `--semi-color-bg-0`，文字 `--semi-color-text-0`

## Design Context

### Users

核心画像：**最终付费用户**（开发者型个人买家或小团队管理员）。
典型场景：
- 注册后做第一次充值 / 订购套餐
- 查看订阅、余额、消耗明细
- 申请 / 下载开发票
- 偶发性地开 key、看日志、跑 playground 调模型

用户心态：花真金白银买 LLM 额度，对**价格透明度**、**支付反馈**、**余额准确性**高度敏感；被 AI 原生后台（OpenAI / Anthropic）训练过眼睛，看到土味后台会当场关闭。

要让他们完成的核心任务（Job-to-be-done）：
1. 在 60 秒内看懂"我还剩多少 / 我花了多少 / 下一笔什么时候扣"
2. 一键完成充值、切换订阅、开票
3. 拿到可用的 API key 和最小可跑的接入片段

### Brand Personality

**三个词：技术 · 锐利 · 现代。**

语气与笔触：
- 像 developer tool，不像"企业管理系统"
- 文案短促、动词优先、不用客服话术（禁"尊敬的用户""小主""亲"）
- 数字大于文字 —— 余额、消耗、价格要成为视觉主角
- 英文术语可直接保留（API Key / Token / Quota / Playground），不强行翻译

情绪目标：**让付费用户觉得"这钱花得放心、花得专业"**。信心 > 热情；克制 > 讨好。

### Aesthetic Direction

参考系（想像它）：
- **OpenAI Platform（platform.openai.com）** — 侧栏克制、卡片信息密度高、usage 图表是主角
- **Anthropic Console（console.anthropic.com）** — 留白大、typography 干净、主色收敛

反参考（绝不要像）：
- 花哨的 Web3 渐变、玻璃拟态满屏浮动
- 传统 SaaS 后台：拥挤的顶栏、彩虹 tag、过度圆角卡通图标
- 国风管理系统：大红大金、报表堆叠、icon 尺寸混乱

主题：
- **明暗双主题，跟随系统**（明为默认）
- **品牌色在双主题下保持感知一致**：主色调应在明暗两套背景上都有足够对比度（≥ 4.5:1 文字，≥ 3:1 大元素），不允许深色主题下主色变浅到失去识别
- 图表（VChart）明暗主题切换时，调色盘必须用 Semi data-0..19 语义色，不得自配

视觉语言：
- 圆角：小（`--semi-border-radius-small` / `medium`）为主，避免大圆角
- 留白：卡片内边距偏大（16–24），卡片之间间距稳定（12 / 16 / 24 三档）
- 阴影：极少使用；边框 + 背景层级（`bg-0` → `bg-1` → `bg-2`）承担分层
- 强调：主色仅用于主 CTA、关键数字、选中态；严禁一屏多个主色按钮

Typography：
- 数字用等宽或 tabular-nums（金额、token、用量务必对齐）
- Heading 字重用 600（Semi 默认），不要 700+
- 代码块：`source-code-pro, Menlo, Monaco, Consolas`（index.css 已定义）

### Design Principles

1. **Money is the hero.** 余额、消耗、价格在任何页面都应是第一视觉焦点，使用最大字号或最粗字重，数字一律 tabular。
2. **Token over hex.** 所有颜色/圆角/间距走 Semi CSS variables 或 Tailwind 映射类，禁止 `#xxxxxx` 硬编码、禁止内联 `style` 写死色值。
3. **One primary per screen.** 每个视图只允许一个主色 CTA，其余按钮降级为 tertiary / text；减少决策噪音。
4. **Density with air.** 像开发者后台那样高密度显示数据，但用稳定的留白节奏（12/16/24）和层级背景切分，不靠边框堆叠。
5. **Dual-theme parity.** 任何新组件必须在明暗主题下都通过对比度检查；图表用 data-n 语义色，不写死 hex。
6. **i18n by default.** 文案进 `react-i18next`，中文为源语言；术语表（API Key、Token、Quota、Playground）保留英文，不翻译。
7. **Semi first, custom last.** 能用 Semi 组件就别写自定义；确需自定义时，先检查 `src/components/common` 是否已有同类封装。
