Desktop ≥ 1024：240px 持久展开

B. 恒定 icon rail + hover 浮层

桌面端侧栏永远是 64px rail，不占持久宽度，鼠标悬停时展开一个 200px 浮层（不挤主内容）。点 📌 可以钉住保持展开。内容区利用率最大化，最适合大表格 / 长图表。
缺点：新手不一定发现 hover 机制；label 不常驻降低辨识度。

C. 不折叠，只有 Desktop / Mobile 两态

桌面端彻底不给折叠选项，永远展开；< 768 直接 drawer。最简单，代码最少，没有第三种状态要测。
缺点：窄屏笔记本（13" 1280 宽）牺牲 240px 给侧栏会很挤；没给 power user 留"我想看更多数据"的通道。

其它子决策（A 方案默认值，选其它方案我再问）

  • 宽度：240px 展开 / 64px rail —— 比当前的 180/60 更宽松，给 label 和 tabular 数字留余地
  • 切换：顶栏图标按钮 + Ctrl/⌘ + B 快捷键（VS Code / Cursor 派）
  • 记忆：折叠状态 localStorage，下次登录保留
  • 折叠时：底部 balance 卡只剩金额数字（无 label、无进度条、无 CTA）；hover 卡出 tooltip 显示完整信息
  • 移动端 drawer：从左滑入，点空白区关闭，路由跳转自动关闭
  • tooltip 延迟：300ms，避免掠过时闪烁
